# 用例 01：都市荒岛求生 · 坠机后和空姐流落荒岛

> 题材：都市 / 荒岛求生 / 生存爽文（男频，含克制感情线）
> 验证点：求生写实 + 人性张力 + 情绪后劲

---

## 企划书

- **一句话卖点**：大学毕业旅行赶上廉价航班，飞机在太平洋上空出事坠海，机械系应届生陈野和空姐林晚及几名幸存者流落无人荒岛——没有信号、没有补给，他们要熬过救援黄金期，也要在人性崩塌前守住彼此。
- **题材**：都市 / 荒岛求生 / 现实向生存爽文（男频为主，感情线克制、推进慢）
- **主角卡**：陈野，22 岁，机械工程系应届毕业生。动手能力强，遇事冷静，有点闷。求生靠知识与拆解，不靠蛮力——知道怎么把残骸变成工具，也知道怎么在绝境里把人心拢住。
- **同伴卡（女主）**：林晚，24 岁，航班乘务员，临时换到本趟航班。专业、要强、嘴硬心软。受过机组应急与急救训练，是幸存者里唯一有救援知识的人。
- **核心冲突**：荒岛上没有规则、没有补给。淡水、食物、火、避难所、伤病、海上的动静——每一步都是生死抉择；而幸存者之间（乘客、机组、陌生人）的信任随时可能崩：藏粮、抢水、夺船。
- **生存设定**：飞机坠海后少数人靠残骸生还，游到一座偏离航线的无人热带岛。求救信标损坏，机组重伤，救援的黄金窗口是前 72 小时——他们必须先靠自己撑住，再等救援或自己找路。
- **目标读者**：18-35 岁，喜欢求生流 / 种田流 / 男频爽文的读者。

## 前 3 章细纲

**第 1 章**：陈野毕业旅行赶上一班廉价航班，机上遇到临时换班的乘务员林晚。起飞一小时后飞机剧烈颠簸，引擎起火，机长宣布迫降海面。混乱中陈野在客舱里帮林晚放下一名被卡住的老人，自己却被甩出断裂的舱门，在浪里抓住一块机翼残骸。结尾钩子：漂了大半夜，晨雾散开，他看见一座岛的黑色轮廓。

**第 2 章**：陈野爬上岸，陆续救起/遇见幸存者：林晚、一个抢先钻进救生艇的中年商人马国栋、一个被浪冲上来的年轻女孩。清点物资：半瓶水、一小包应急口粮、一个进水没信号的手机。林晚按培训教大家分工——找水、生火、搭棚。结尾钩子：夜里，他们听见树林深处传来不属于风声的动静。

**第 3 章**：陈野用残骸里的金属片和椰子纤维做了简易刀与汲水器，找到一处淡水泉眼。分水时马国栋想把水私藏，还从应急包里抠出半包饼干。陈野当众拆穿他，把物资归公、定下分配规矩。结尾钩子：傍晚海面出现一艘船的影子，绕岛转了一圈却没靠岸——它开走了，没人知道它有没有看见他们。
