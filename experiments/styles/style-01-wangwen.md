# 文风卡：网文 · 白话爽感（style-01-wangwen · 第三人称）

> **一句话定位**：白话直给的"爽感"叙事——名字领句、对话驱动、心理直接说，苦难是背景板、主角的聪明是底色，情绪给足不藏。读起来顺、快、有满足感。
> **叙事视角**：整卡一律**第三人称**，全知偏主角。出现"我"（第一人称）即违规。

## 一、句式节奏
- **名字领句**：主角的名/代词常做句首主语，一串句子连续"XXX + 动作"下去。这是最醒目的指纹。
- 短句为主，一句一个动作或一个判断；中长句只留给"交代背景 / 算账 / 讲原理"。
- 逗号推进、句号顿住；一段只干一件事（一个动作 / 一句对话 / 一段心理 / 一次交代）。
- 对话标签用"说道 / 笑道 / 开口 / 问道 / 答"，**不换花哨动词**（不写"他狞笑道""她低语呢喃"）。

## 二、词汇
- 纯白话，不认生僻字；程度副词（十分 / 相当 / 很 / 极为）给情绪加码，可用但别滥用。
- 成语家常（轻车熟路 / 一目了然 / 无影无踪），不炫技、不连用。
- 心理活动**直接说**："心里"二字一开，替主角把心思点破——"心里已然猜到""心里开始琢磨"。
- 情绪直给："十分惊喜""内心激动不已""乐开了花"，不羞于把高兴 / 占便宜写出来。
- 生活化 + 轻微夸张的比喻："简直就跟被狗撵了一样""跟天上掉馅饼差不多"。
- **算账过程写出来**：价格、斤两、算式、收益，让读者数着明白主角占了多大便宜。

## 三、叙述距离
- **第三人称，全知贴主角**：重心永远在主角；作者却能随时切进旁人脑子，用旁人心态对照出"主角占上风"。
- 叙述者用人称代词"他 / 她 / 他们"，不换成"我"；主角内心用"他心里"引出，不写成"我想"。
- 说书人式评点偶尔跳出来，一句带过："做人做到这个份上，可以说是毫无亲情可言"。
- 不玩文字迷宫；读者代入的是"我知道主角接下来要赢"的爽感。

## 四、详略取舍（指纹）
- 把"动手、算账、谈判、过招、讨价还价"这类正在进行的角力拉开写、一步步跟；一笔带过的是"环境、季节、身世、背景交代、时间的流逝"。
- **重对话、轻陈述**：信息主要靠对话推给读者，旁白少；一两句能讲清的背景，不铺陈。
- **详略的极度反差**：一段里能用一个动作 / 一次过招写得极细；一次转场、一段岁月，半句就带过去。

## 五、情绪基调（指纹）
- **直给、偏热、不藏**：情绪不压着也不克制，想高兴就写高兴、想冷就写冷——它不玩"藏一半让读者猜"。
- **允许说书人的调侃 / 幽默**："那样子就跟被狗撵了一样"——叙述者能带一点轻松的戏谑，不端着。
- 基调可暖（底层朴素）可冷（大佬冷面），**但"直给不藏、偏轻、会调侃"这个声音指纹不变**。

## 六、修辞与衔接（指纹）
- **强调、点题的口头禅**：爱用"简直就跟…一样 / 差不多""这就…吧""可谓"来把话钉牢。
- **推进的衔接词**："随即 / 紧接着 / 很快 / 过了片刻 / 不一会儿"——节奏不拖沓。
- **暗线点到即止**：用"暗 / 隐约 / 仿佛"吊一下，不解释，留给下文。

## 反例（这么写就"不网文"，丑）
- 文绉绉、绕弯、用冷僻词、堆华丽比喻——网文要顺、直、快。
- "他心下五味杂陈，一时百感交集"这种老派抒情，搁网文里就闷 → 应写"他心里乐开了花"，或直接给一个动作。
- 花哨对话标签（他狞笑道 / 她低语呢喃）→ 只用"说道 / 笑道 / 问道"。
- 环境来历人物背景写成一大段 → 网文是**背景快进、过程慢镜头**。
- 作者藏起来不表态，全靠读者品 → 网文作者要跳出来说书人式地点一句。

## 声音范例（示范卡本身的声口，内容随意）
> 李大叔见他盯着那台落灰的仪器，笑了："怎么，你也有兴趣？"
> 他心里早就乐开了花，脸上却装出一副为难的样子："能让我看看吗？"
> "看吧看吧。"李大叔摆手，"也就你把这玩意儿当个宝。"
> 他蹲下身，指尖在那团铁疙瘩上摸过，心跳快得厉害。这玩意儿他在书里见过，从没摸着过真的。要是能弄到手……
> 他咽了口唾沫，尽量让声音平缓："李叔，这个……怎么卖？"
> 李大叔挠了挠头，故作沉吟："这玩意儿也不轻，我老远运回来的，怎么着也得……你给十五块吧。"
> 他差点当场笑出声。十五块？他心算飞快——这东西在市面上，少说值一万。
> "十五块？"他皱起眉头，"李叔您可别逗我，这铁疙瘩，废铁都不好卖。"
> 他嘴上说得嫌弃，眼睛却一眨不眨盯着那团疙瘩，心里只有一个念头：这个便宜，他今天捡定了。
