# 用例 06 · 女频古言：重生嫡女的退婚局

【题材】女频 · 古言 · 宅斗 · 重生

【前情】谢云窈十六岁，永宁侯府嫡长女。母亲三年前病逝，母亲留下的嫁妆铺子和田庄暂由祖母代管。父亲宠妾柳姨娘，柳姨娘想把云窈嫁给自己娘家侄子赵砚，好名正言顺吞掉嫁妆。上一世云窈嫁了，三年后赵家败落，她被休弃，死在庄子上。重生回来，她记得赵砚在外头欠了赌债，也记得柳姨娘挪用过母亲的嫁妆。

【这场戏】老夫人寿宴前一日，下午，老夫人院里。柳姨娘带着赵砚来“请安”，提起两家结亲的事；老夫人倾向答应。云窈不能直接撕破脸，她要当众退掉这门亲，同时保住母亲的嫁妆。

【必须发生】
1. 柳姨娘先开口，把结亲说成“亲上加亲”；赵砚装斯文；老夫人没有立刻点头，但明显被说动。
2. 云窈不哭不闹，先顺着长辈的话说，再把话题引到赵家的“诚意”上；她拿出一个具体证据（赵砚的赌债、柳姨娘挪用嫁妆的账、或赵家送来的聘礼单里的破绽），但不把话说死。
3. 老夫人的态度发生变化；柳姨娘反咬一口；云窈用一句更软的话把祖母的面子保住，同时把婚事拖黄。
4. 赵砚或柳姨娘撂下一句威胁；或者老夫人提出一个更难的要求（比如让云窈交出母亲留下的铺子）。
5. 结尾落在一个新问题/新算计上，不要用“且等……再说”收束。

【写法要求】
- 女频古言/宅斗/重生：第三人称贴身，叙述者讲透人情世故与内宅算计；称呼、位份、衣裳首饰要具体。
- 心理直给，带理由；对话话里有话；女主靠信息差、人情、规矩和提前布局赢，不靠天降。
- 3000–4000 字。只输出正文，不要标题、提纲、说明。
