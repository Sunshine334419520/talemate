# 用例 02 · 旧货市场讨价还价

【场景】周六清晨的旧货市场。陈默看中一台被摊主当废铁卖的旧仪器，摊主开价三百。陈默知道仪器里有一块还能用的进口机芯，但他不能说破。

【人物】
- 陈默：二十四岁，修表铺出身，懂行，缺钱，嘴上不饶人。
- 摊主老周：五十多岁，收旧货的，精明，喜欢试探人，吃软不吃硬。

【本章必须发生】
1. 陈默先挑毛病，把价格往下压；老周不接招，反问他“你一个修表的，买这个干什么”。
2. 陈默用一个只有懂行的人才看得出的细节，证明自己不是外行，同时把老周的注意力引开。
3. 两人来回三轮，最后成交；陈默以为自己占了便宜，收尾发现老周也在算计他——或者有人一直在旁边看着。

【写法要求】
- 重对话、重心理、重算账；动作慢放，背景快进。
- 第三人称，贴着陈默；他心里那本账要让读者看见。
- 2000–2500 字。结尾留钩子。
- 只输出正文，不要标题、提纲、说明。
