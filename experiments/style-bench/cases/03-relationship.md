# 用例 03 · 旧铺子里的一场对话

【场景】傍晚，旧修表铺。陈默在整理父亲留下的工具，房东的女儿沈知夏来送最后一份腾退通知。两人小时候在这条街上一起长大，后来因为陈默父亲的事闹翻，三年没好好说过话。

【本章必须发生】
1. 沈知夏把通知放下，话说得很公事公办；陈默用一句带刺的话把她顶回去。
2. 两人从腾退争执到三年前那件事；谁都没有把最关键的那句话说透，但读者能听出来。
3. 一个具体的动作让关系松动一点（递工具、倒水、修一件她带来的旧表，任选其一）。
4. 收尾：门外传来动静，或者陈默的手机响了——外部威胁打断，留下钩子。

【写法要求】
- 不要写成纯文学式的沉默和留白；情绪要直给，读者要知道两个人各自在憋什么。
- 对话为主；叙述者的调侃和判断可以有。
- 2000–2500 字。结尾留钩子。
- 只输出正文，不要标题、提纲、说明。
