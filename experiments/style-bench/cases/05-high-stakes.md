# 用例 05 · 高赌注场景：今天五点前必须拿到三百块

【题材】男频 · 年代市井 · 单场戏

【前情】周满二十岁，在老街口开一间家电修理铺。铺子是父亲留下的，欠着三个月房租。妹妹周小满十五岁，先天性心脏病；县医院说今天下午五点前交三百块，才能排上明天的手术，交不上，床位就让给别人。

【这场戏】下午三点，周满拎着工具包，站在县医院院长家的客厅里。院长夫人托人找到他，说她娘家陪嫁的一台进口录像机坏了，县里没人敢修；修好了给三百，修不好一分没有。客厅里还有院长儿子请来的一个中年技师，姓秦，穿白衬衫，已经拆了半天没修好，正说是“磁鼓坏了，得换总成，县城买不到”。

【必须发生】
1. 周满先不看机器，先看人：院长夫人的着急、院长儿子的不耐烦、秦技师的笃定。他心里有自己的判断。
2. 他拆机、诊断，用一个秦技师没注意到的细节，指出问题不在磁鼓，而在别处（具体是什么，你定）。
3. 秦技师不服，院长儿子要赶他走；周满用一次当场验证，把局面翻过来。
4. 修好之后，院长夫人给钱，但院长儿子想赖掉一部分；周满不能翻脸，也不能吃哑巴亏，他用自己的办法把钱拿到手。
5. 收尾：他揣着钱出门，发现秦技师在楼下等着他；或者院长儿子撂下一句威胁。留一个让人想继续听的问题。

【写法要求】
- **讲述体**：叙述者在场，有自己的态度；段落可以长，长段讲清来龙去脉，短句砸重点。
- 心理直给，带理由；对话嵌在叙述里，允许寒暄、客套、绕弯。
- 拆机、诊断、验证的过程要铺开写，不要一句“他修好了”带过。
- 不要镜头切，不要一句一段的动作清单，不要只给结果。
- 3000–4000 字。结尾留钩子。
- 只输出正文，不要标题、提纲、说明。
