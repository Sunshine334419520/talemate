# 用例 04 · 讲述体开篇

【题材】男频 · 年代市井 · 连载开篇

【主角】周满，十六岁，父母早亡，跟奶奶住在县城老街。奶奶病重，他白天上学，早晚帮人修自行车、收废品。老街上的街坊都认识他，有人照顾，也有人欺负。

【本章要讲的事】
1. 从一个冬天的清晨讲起：周满起床、给奶奶熬药、出门收废品。把人物、家境、街坊和这条街讲清楚。
2. 在废品站，他看见一台被人当废铁卖掉的旧收音机。他懂一点，知道里面有值钱的东西，但不动声色。
3. 和废品站老板讨价还价，把称重、算账、试探的过程讲出来。
4. 收尾：他抱着东西回家，发现奶奶的病情加重；或者有人一直在暗处看着他。留一个让人想继续听下去的问题。

【写法要求】
- **讲述体**：叙述者在场，段落可以长，前因后果要接上；日常过程铺开写。
- 不要一个动作一段，不要镜头切，不要急着进入事件。先把人和处境讲清楚，再让事情发生。
- 第三人称；心理直给，但要带理由。对话嵌在叙述里，标签用“说道 / 笑道 / 问道 / 答道”。
- 2500–3500 字。结尾留一个让人想继续听的问题，不要总结主题。
- 只输出正文，不要标题、提纲、说明。
