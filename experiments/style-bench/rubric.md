# 文风盲评表

先读三遍再打分。**不要评“文笔好不好”**，只评“像不像有人在讲故事、读起来顺不顺”。
每项 1–5 分：1 = 明显不是，3 = 一般，5 = 很到位。

| 维度 | 1 分的样子 | 5 分的样子 | 这篇 |
|---|---|---|---|
| **讲述感** | 像镜头在切、像提纲在推进 | 像有人在讲故事：有前因后果，有叙述者的声音 | |
| **自然** | 对话像念台词、像信息播报 | 对话和叙述像真人说话，有寒暄、有绕弯 | |
| **清楚** | 不知道为什么发生，人物在干什么要靠猜 | 人物要什么、怕什么、事情为什么发生，读者明白 | |
| **代入** | 像旁观者在写总结 | 贴着主角，能感到他的得失 | |
| **网文味** | 像出版文学/作文 | 像连载网文：直给、有钩子、有读者的位置 | |
| **节奏** | 一路赶，或者一路拖 | 该慢的地方慢下来，该快的地方不拖 | |

## 三个必答问题

1. **这篇有没有“镜头切”？** 例如“他骑车拐上大路。手机震了。房东微信。绿灯。”——把这种句子圈出来。
2. **哪一段最像“讲故事”？** 把那一句/那一段抄下来，写一句为什么。
3. **如果把这篇发到网文平台，读者会在第几段划走？** 为什么？

## 两两比较

同一用例的 A/B/C… 放在一起读，回答：

- 哪一篇最像“有人在讲故事”？为什么？
- 哪一篇最像“镜头在切”？为什么？
- 如果把两篇的优点合成一篇，你会保留哪几段、删掉哪几段？

## 不要做的事

- 不要因为“文笔更高级”给高分。讲述体要的是顺、自然、明白、有人味。
- 不要因为“节奏慢”直接扣分；先看慢下来的地方有没有在讲故事，还是只是在拖。
- 不要一次评太多篇。一个用例 4–6 篇足够；评多了会疲劳，结论不可靠。
