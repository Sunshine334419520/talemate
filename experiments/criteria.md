# 单章审判判据（通用 · 第一版）

> 用途：审判 Agent 逐情节、逐段审查单章时的尺子。这是**审判用的判据**，不是写手的写作标准——写手保持自由，审判按这两套尺子量稿子。
> 状态：通用版，跨题材；题材权重差异（网文/悬疑/都市…）后续再按需加权。
> 审查架构：拆情节 → 逐情节深审 → 汇总（见 src/run.ts 与 src/prompts.ts 的三遍式）。

---

## 一、情节（Beat）好设计 —— 6 条

1. **有任务**：这个情节在章节里承担明确的活（铺垫 / 突发 / 反应 / 转折 / 收尾 / 钩子），跟本章任务对得上。答不上"它干嘛用的"就是废情节。
2. **有微弧线**：从状态 A 到状态 B——起于目标 / 问题，遇阻碍，出转折 / 决定，落到新状态（B≠A）。一段串不出变化的，不是情节。
3. **有因果链**：结尾要么是下个情节的原因，要么抛出一个非答不可的问题。情节是**链条**不是堆叠。
4. **信息释放**：该揭的揭、该藏的藏。理想 = 答一个问题 + 抛一个新问题。
5. **张力有起伏**：冲突 / 发现 / 决定处紧，过渡 / 交代处松，不一个力度到底。
6. **必要与衔接**：删掉它章节会不会塌？跟前后因果成立、不凭空跳。

## 二、段落（Paragraph）优秀 —— 6 条

1. **一段一功能**：一个观察 / 一个动作 / 一问一答 / 一次推进。塞两件事就拆段。
2. **镜头可见**：具体动作与物象，不写概括（"气氛压抑""大家议论"）。
3. **对话自然**：有停顿 / 试探 / 潜台词，不教科书问答，标签不花哨。
4. **无 AI 腔**：无套话黑名单（涌起、仿佛、一抹、嘴角勾起、心中闪过、眼中闪过一丝、空气仿佛凝固、内心五味杂陈……），不堆形容词副词，不重复信息。
5. **有承重**：每段推进情节 / 立人物 / 放信息——"删掉无感"的段就是废段。
6. **情绪有着落**：重要情绪有动作 / 物象 / 台词承载（网文可直给，但要有具体着落点）。

## 三、执行铁律（审判 Agent 逐条照做）

- 每条 ✅/❌ 必须引用原文一句作证据；引用不出来的判断不算数。
- 逐情节深审时只评本情节，不评价前后；衔接问题在汇总层看。
- 从严：找不到硬伤 ≠ 没问题，是你没看够；宁可误伤，不可放水。
