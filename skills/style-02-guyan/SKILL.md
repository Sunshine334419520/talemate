# 女频古言：内宅人情与重生算计

一句话：第三人称贴着女主，叙述者像坐在读者对面讲内宅八卦——谁和谁是什么亲戚、谁在打什么算盘、女主心里怕什么，都讲明白。情绪要足，算计要透，称呼和衣裳要像那个时代。

## 叙事视角

- 第三人称，重心永远在女主；但叙述者是全知的，可以切进丫鬟、嬷嬷、婆婆、婶娘的脑子，用他们的心事对照女主的处境。
- 切视角要有叙述者的口吻：用“她不知道”“她心里想的是”“原来”这类过渡，别让读者以为是女主知道的。
- 叙述者可以评价人物、解释关系、提前点破阴谋；不要做冷冰冰的摄像机。
- 女主的前世/重生信息是她的底牌。叙述者可以写她心里的对照，但不要一次把底牌摊给所有人。

## 句式与语言

- 半文半白的古言白话：能读懂的旧时味道，不是文言文。用“这会子 / 昨儿 / 瞧 / 呦 / 可不是 / 说到底 / 说白了 / 想来 / 估摸着 / 巴巴的 / 好不……”这类口语。
- 中长句为主，四字词、俗语、反问、感叹都可以用；该慢的地方把人情、利害、规矩讲透。
- 称呼必须准确：老夫人 / 夫人 / 姨娘 / 小姐 / 姑娘 / 嬷嬷 / 丫鬟 / 婢子 / 奴婢 / 儿媳 / 妯娌 / 嫡出 / 庶出。称呼变化就是关系变化。
- 不要现代词、网络梗、翻译腔；不要为了古味堆生僻字和繁体字（除非这本书的设定要求）。

## 心理与算计

- 心理直给，而且带理由：她怕什么、护什么、算什么、下一步打算怎么办，读者要知道。
- 女主不是纯圣母，也不是纯爽文机器；她的每一步要能算得过来：信息差、人情、规矩、银子、时间。
- 叙述者可以替读者把“她为什么这么做”讲明白；也可以让她自己吐槽“这日子真没法过了”。
- 重生/先知信息用来做判断和布局，不要用来开天眼。她可以知道大事，但不必知道每个人的每个细节。

## 对话

- 对话嵌在叙述里，前后有动作、神情、称呼；谁对谁说话、用什么位份称呼，决定语气。
- 内宅话里有话：表面客气，底下试探、敲打、撇清、告状；叙述者可以点破对方真正想干什么。
- 对话标签用“笑道 / 问道 / 斥道 / 柔声道 / 吩咐 / 回了句 / 嗔道”，不花哨；不要每句都“说道”。
- 对话可以长，可以有寒暄、客套、绕弯；不要把所有人都写成同一种腔调。

## 细节

- 衣服、首饰、料子、花色、茶、炭火、院子、摆件要具体，用它们显示身份、财力、性格、处境。
- 细节要服务于人物和场面，不要堆成清单；一段里一两个准的细节，比十个形容词有用。
- 内宅的空间和规矩要清楚：谁住哪个院、谁能进哪个门、谁在门外等、谁坐哪个位置。

## 情绪

- 女频的情绪要足：委屈、心疼、恨、怕、得意、暖，都可以直接写；不要冷冰冰的纯客观。
- 女主要有“想要”和“怕失去”的东西；她的情绪要落在具体的人和事上。
- 可以煽情，但要给读者一个具体的画面或动作，不要空喊“她好难过”。
- 前世/今生的对照可以用，但不要每段都回忆；一次对照要有新信息或新情绪。

## 关系与反派

- 每个人都有自己的利益和立场：嫡庶、长房/三房、婆媳、主仆、姻亲；反派不是纯工具人。
- 反派要有自己的算盘、资源和反扑；她的失败要留下残余和旧怨。
- 女主的胜利靠信息差、人情、规矩和提前布局，不靠天降；可以借力，但要知道借的是谁的力。
- 配角要有功能：镜子、阻力、资源、代价、笑点；不要只当背景板。

## 章节钩子

- 结尾落在一个新问题、新算计、新威胁，或一句意味深长的话；不要用“且等……再说”收束。
- 钩子要从前面的结果里长出来，不要天降一个更强的敌人。
- 感情线的钩子可以是误会、身份、选择、代价，不要只有“他到底爱不爱我”。

## 不要（这么写就不是这个声音）

- 不要现代词、网络梗、翻译腔。
- 不要冷冰冰的镜头式短句，不解释关系、不写心理。
- 不要把宅斗写成打怪：赢要靠规矩、名声、人情、证据，不是谁嗓门大。
- 不要所有人一个腔调；称呼、位份、亲疏要分得清。
- 不要堆衣服首饰不服务人物。
- 不要反派只会嚣张，没有自己的算盘。
- 不要女主一路开天眼，所有事都提前知道。
- 不要每段都回忆前世，情绪要往前走。

## 声音范例（学节奏与叙述方式，不要抄内容）

> 沈令仪跪在蒲团上，膝下的青砖凉得刺骨，她却连眉头都没皱一下。
>
> 堂上坐着祖母，左边是大伯母，右边是二婶娘，三个人六只眼睛，全落在她身上。
>
> 她心里明白，今天这一出，不是为了她打碎的那只汝窑盏，是为了她母亲留下的那间铺子。
>
> “令仪，”祖母开口，声音不高，“你母亲走了三年，那间铺子，也该交回公中了。”
>
> 沈令仪抬起头，眼圈红得恰到好处：“祖母说得是。只是铺子里的账，一直是母亲亲手记的，孙女怕交出去，旁人看不懂。”
>
> 二婶娘的笑僵了一瞬。
>
> 她心里冷笑：果然，等的就是这一句。

> 说起来，沈家这三位夫人，没一个是省油的灯。
>
> 大伯母出身侯府，最重规矩；二婶娘娘家有钱，最会算账；祖母年轻时也是从后宅里杀出来的，什么把戏没见过。
>
> 令仪一个十二岁的丫头，夹在中间，稍不留神就要被人拿去做筏子。
>
> 可她偏偏不是从前那个令仪了。
