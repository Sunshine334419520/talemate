# 讲述体：像说书人一样讲故事（第三人称）

一句话：读者要听一个故事，不是看一串镜头。叙述者知道前因后果，有自己的态度，负责把人和事讲明白。

## 八条指纹

1. **叙述者在场。** 他不是摄像机，是一个知道前因后果、会解释、会点评的说书人。可以告诉读者“为什么”“后来怎样”“可惜的是”。
2. **段落是完整的一件事，句子以中长句为主。** 一段从背景、原因或处境写起，落到动作、对话或反应；允许长段。句子用逗号把原因、转折、补充接在同一句里，不要一句一个动作地断；短句只用来砸重点，不是默认节奏。
3. **因果和时间要接上。** 用“因为 / 所以 / 于是 / 随后 / 等到 / 后来 / 可惜的是 / 不过 / 即便如此”把事件串起来。不要用硬切。
4. **心理直给，而且带理由。** 不只写“他心里一紧”，要写清他在盘算什么、怕什么、为什么这么想。
5. **对话嵌在叙述里。** 对话前后有动作、神态、环境；标签用“说道 / 笑道 / 问道 / 答道”。对话可以有寒暄、客套、绕弯。
6. **该慢就慢。** 日常、算账、讨价还价、拆机、走路、干活都可以铺开写；读者享受的是过程，不是只等结果。
7. **转场用叙述带过。** 时间、地点变了，让叙述者把这一段路、这一段时间讲出来；不要用一串短句硬切。
8. **说书人的点评和反问。** 偶尔跳出来一句“你说这上哪说理去？”“可惜的是……”，但不要每段都升华。

## 叙述者的态度（“一般”和“好看”的分界）

- **该夸就夸，该损就损。** 不要只做客观记录；叙述者可以评价人物、替读者感慨、下判断。
- **允许口语。** 重复、反问、俗语、顺口溜都可以用；不要每句都写成书面描述。
- **长短要有落差。** 长段讲清来龙去脉，短句砸一下情绪或转折；不要通篇一个力度。
- **细节要有生活。** 用一两个“只有这条街、这个人”的东西，不要堆年代道具清单。
- **人物要有具体的想要和怕。** 叙述者站在他这一边，读者才知道该替谁着急。

## 不要（尤其是镜头切）

- **不要镜头切。** 例如：“他骑车拐上大路，手机在支架上震了一下。房东发来的微信，三段，他趁着红灯点开。绿灯。”——这是分镜，不是讲故事。要改成叙述者把这一段讲出来。
- **不要一句一段的动作清单。** “他停下车。拔钥匙。上楼。开门。”——连成叙述，带上原因和感受。
- **不要只给结果。** “他砍价成功，买下了电脑。”——把讨价还价、拆机、验证的过程讲出来。
- **不要心理只有标签。** “他心里一紧。”——写清他为什么紧、接下来打算怎么办。
- **不要文绉绉的比喻和整段环境描写。** 白话、顺、明白；但不要为了“快”把叙述者删掉。

## 声音范例（学叙述节奏，不要抄内容）

> 1998 年的冬天，城南的清晨来得特别晚。说是清晨，其实天还黑着，街上除了扫地的环卫工，就只有早点摊的炉子冒着白烟。
>
> 陈默今年二十四，在这条街上送了三年外卖。他父亲留下的修表铺就在街尾，八个平方，一张工作台，两把椅子，墙上挂着一排修了一半的钟。铺子下个月就要被房东收回去。这事他谁也没告诉，每天照旧开门，照旧接单，好像只要他不提，日子就能这么过下去。
>
> 那天凌晨，他送完最后一单，骑车经过纺织厂后巷。巷子里有人在吵。他本来不想管——电瓶车还剩一格电，他只想赶紧回家睡觉——可那两个人正好堵在路中间，一个揪着另一个的领子，骂得很难听。
>
> 陈默把车停在巷口，脚撑着地，看了一会儿。他看见老头袖口上缺了一颗扣子，也看见年轻人裤兜里鼓出一块长方形的轮廓。他心里已经有了数，只是还没想好要不要管。

> 周满把改锥插进后盖缝里，手腕一别，塑料壳“咔”地裂开一道口子。院长夫人往后退了半步，嘴里“哎哟”了一声，像是那壳子夹了她的手。
>
> 周满没抬头。他心里清楚，这台机器要是修不好，今天这三百块钱就没了着落；妹妹还在医院走廊上等着，护士说了，五点之前不交钱，床位就得让给别人。
>
> “你到底行不行？”院长儿子在旁边催，“不行别硬拆，拆坏了你赔得起吗？”
>
> 周满把改锥放下，抬起头看了他一眼。他心里有火，脸上却没露：“行不行，得拆开看。您要是信不过我，现在就可以换人。”
>
> 话说得不软。院长夫人和儿子对看了一眼，谁也没接话。
