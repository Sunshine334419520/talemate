# 正文文风纪律

写正文的规矩只有这一处。写之前读它，然后一次写完——不要边写边回来查。

## 硬纪律

- **只写在材料里已经定下的东西。** 不现编设定，不与核心设定 / 世界观 / 人物卡打架。这一章该立住
  谁、该兑现什么，看这一章的规划。
- **白话现代中文。** 不要文言腔、翻译腔、网络梗。
- **不堆形容词与副词。** 「仿佛」「不禁」「缓缓」这类词，删掉之后句子仍然立得住，就删掉。
- **同一件事不说两遍。** 不替读者总结情绪，不复述上一段刚讲过的动作。
- **拿不准时，写最克制、最普通的那一版。** 想加一句"更有味道"的话之前先问自己：删了它，读者会
  漏掉什么？答不上来就删。

## 只写正文

正文里**只有正文**：不要标题、不要章号、不要小节标题、不要分隔线，也不要解释、评论，或在文末
留"（待续）"这类话。要说明的话，对用户说，不要写进正文。

## 落盘

正文写 `chapters/chapter_ch<N>_v<M>.md`（N = 章号，M = 第几版）。落盘走 `write` / `edit`，
用户会看到 diff 并点头——**用户看过的字节就是落盘的字节**。
