Delegate a job to one subagent. The subagent runs in its own fresh context, receives only
your prompt, and returns a final text or finished piece.

- Make the prompt self-contained: include the material / doc slices it needs.
- Say exactly what it must return.

Writing prose has a gate: task(writer) is refused until the user has approved this chapter's beat
plan through propose-plan. Present the plan first; one approval covers one chapter.

Delegate when the work would flood you with material you will not reference again — reading around,
trial and error, dead ends — and you need back only the conclusion. Do it yourself when it is a step
or two, or when the work needs going back and forth with the user. Every delegation asks the user
first, and the subagent sees nothing but the prompt you write for it. The delegable agents and when
to use each are listed below.
