Update one or more sections of an existing character card; sections you do not pass stay
unchanged, including custom ones.

name identifies the card. Pass only the sections to change, by key: profile / want_fear /
bottom_line / idiolect (常驻带), and contradiction / origin / quotes / body_habit / relations /
ability / arc / function (按需格). Body text must not contain heading lines — the tool writes
the heading itself.

Passing a section as （待定） reserves it unfilled. `当前` is maintained by the chapter
write-back, not here. If the card does not exist, use add-character instead.
