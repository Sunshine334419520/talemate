Ask the user 1–3 concise, self-contained questions when an answer cannot be inferred from the
project or the conversation. Use it for creative choices, missing preferences, and decisions
between options with real trade-offs — not for permission (use confirm), for facts you can read,
or for "may I start". If only one option is actionable, act and explain.

Give each question a stable id. Offer 2–5 options when choices exist; put your recommendation
first and end its label with （推荐）. Each option's description says what it buys and what it
costs. Use multi_select only when choices are not exclusive. The user may type a custom answer
or skip; an empty answer is a skip, not consent.

timeout is seconds for the whole batch (default 120); use -1 only when you cannot proceed
without an answer. A timeout is pending, not skipped: the turn ends, the user can still answer,
and you must not act as if they agreed.
